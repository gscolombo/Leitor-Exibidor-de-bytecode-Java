Descrição detalhada

Funções para exibição do Constant Pool de um ClassFile.

Este módulo fornece rotinas para imprimir em formato legível cada entrada do constant pool, interpretando:

  • literais numéricos
  • referências a classes, métodos e campos
  • strings UTF-8 decodificadas
  • NameAndType
  • MethodHandle / MethodType / InvokeDynamic

É usado internamente por show_classfile() em writer.c.

◆ show_constants()

void show_constants ( u2  count,
cp_info *  _cp 
)

Exibe todas as entradas do constant pool.

Percorre o array de cp_info e imprime cada entrada no formato:

#<index> = <TagName> <Detalhes>

Exemplos:

#1 = Utf8 "java/lang/Object"
#2 = Class #1
#3 = Methodref #2.#5 // java/lang/Object.<init>()V

Observações:

  • A função apenas exibe, não altera nem libera o constant pool.
  • As strings UTF-8 já devem estar decodificadas (campo UTF8.str).
Parâmetros
countNúmero total de entradas no constant pool (u2).
cpPonteiro para o array de entradas cp_info.

Para cada entrada, a função imprime uma linha no formato: #<index> = <TagName> <Detalhes>

A função alinha os índices à direita calculando quantos espaços são necessários conforme o número máximo de entradas (count).

Parâmetros
countNúmero total de entradas no constant pool (u2).
_cpPonteiro para o array de cp_info (constant pool).
